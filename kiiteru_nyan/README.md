# 聞いてるニャ（kiiteru-nyan）

会話を代わりに聞いておいて、その中の「予定っぽいもの」「手順っぽいもの」を拾い、一覧にして見せる道具です。本人はそれを見て、**要るものだけ選び、違うものは捨てます**。

ちびロボ・シリーズの1つ。`kiiteru_nyan_v2.html` **1ファイルだけで動きます**（ビルド不要・外部ライブラリなし）。

---

## 誰のため・何を助けるか

聞いたことを覚えておくのが難しい人のための道具です。つまずくのは、だいたいこの3か所：

| つまずく場所 | 起きること | この道具の答え |
|---|---|---|
| 聞き取り | うまく聞き取れない | 代わりに聞いておく |
| 書き込み | 覚える前に次の話が来て消える | その場で書き留める |
| 引き出し | "見出し"が無くて探せない | 探させない。先に一覧で出す。聞いた日時を見出し代わりに付ける |

使う人の言葉でいうと、欲しいのは **「これがあれば怒られない」** です。

## 使い方（まず触ってみる）

1. `kiiteru_nyan_v2.html` を **Chrome か Edge** で開く
2. 「アプリを開く」→「✍ 文字で入れる」→「サンプル会話を入れてみる」→「ここから拾う」
   （ここまではマイク不要。一通りの流れが分かります）
3. マイクで試すなら「👂 聞いててにゃ」（マイク許可が要ります）

マイクは `https` か `localhost` でないとブラウザが渡しません。詳しい開き方・スマホでの注意は **[仕様メモ](./仕様メモ.md) の §2**。
（GitHub Pages を有効にすれば、リンクを開くだけで使える版になります。）

## 直す人へ（ここが一番大事）

コードは叩き台です。**どんどん直してください。** ただし——

> **[仕様メモ](./仕様メモ.md) の §4「変えないでほしい方針」（8つ）だけは、直す前に相談してください。**

善意の改良で一番壊れやすい所です。ざっくり8つ：

1. **杖であって、代行ではない**（決めるのは本人。勝手に確定しない）
2. **先に出す（push）。探させない（pull しない）**
3. **「らしきもの」で止める**（`?` は消さない＝訊くきっかけ）
4. **思い出させない。見て選ばせる**
5. **非難しない**（ネコ口調と"テキトーに拾ってきた感"は飾りでなく、間違いを許せる空気を作る機能）
6. **一点から**（聞く→拾う→選ぶ の質を上げる方を優先）
7. **分からなかったら誰かに見せる**（聞いた時刻は、機械が保証できる唯一のタグ。推測で埋めない・後から書き換えない）
8. **「誰かが居ないと回らない」を作らない**（＝紙オムツ目標。文書に残す／部品は差し替え可／特定サービス依存にしない）

**なぜそうなのか**は仕様メモに書いてあります。機能一覧より先に、そこを読んでください。

## 構成・差し替え口

1ファイルの中が2つのスクリプトに分かれています：

- `<script id="core">` … 画面に触らない純ロジック（日付解決・かんたん版の抽出・LLM用プロンプト・`.ics`生成）。**Node でそのまま読める**のでテストしやすい。
- `<script id="app">` … 部品と画面。

差し替えを想定している部品は2つ：

| 部品 | 役目 | 約束（インターフェース） | いまの中身 |
|---|---|---|---|
| `Listeners` | 聞く→文字 | `supported()` / `start({onInterim,onFinal,onState,onError})` / `stop()` | ブラウザ内蔵の音声認識（Web Speech API, `ja-JP`） |
| `Extractors` | 文字→らしきもの | `async (text, now) => [item…]` | `rule`（正規表現・鍵いらず）／`llm`（OpenAI互換 または Anthropic） |

保存（`Store`）は localStorage。`all / get / add / update / clear` の5つを保てば差し替え可。
ブラウザのコンソールから `Kiiteru.feed('明日の14時に歯医者', 'text')` のように直接流し込めます。

## どこに何が出ていくか（プライバシー）

- 拾った一覧は **その端末のブラウザの中だけ**。**録音は残しません**。
- 「かんたん版」は文字を外に出しません。「LLM版」は会話の文字を、設定した宛先に送ります。
- ブラウザの音声認識は、既定では音声を外部サーバーで処理します。
- APIキーもブラウザに保存されます。**共有のパソコンでは入れないでください。**
- 周りの人の声も入る道具なので、現場で使う時は運用（同意・保存範囲）の設計が要ります。
